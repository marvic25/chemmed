# ChemMed — Editor Molecular

App web de química médica para ensino de Farmácia. Arquivo principal: `build5.py` → gera `chemmed5.html`.

**Uso**: Restrito aos estudantes de Farmácia em aulas com Msc. Marcos Gregório (UNINASSAU).

Para gerar o HTML: `python3 build5.py`
Dependência: `npm install smiles-drawer` (em `/tmp/chemapp/` ou local)

**Deploy**: GitHub Pages → https://marvic25.github.io/chemmed/

Desenvolvido por Msc. Marcos Gregório — UNINASSAU, Farmácia.
